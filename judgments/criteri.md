# Criteri di rilevanza per le query sul contenuto

Un documento è rilevante (1) se il suo argomento principale soddisfa il criterio della query; non basta che le parole della query compaiano nel testo. In caso di dubbio: 0.

| Id | Query | Rilevante se l'articolo parla di... |
| --- | --- | --- |
| C01 | calciatore serie A | un calciatore che ha giocato nella Serie A italiana |
| C02 | "seconda guerra mondiale" | un evento, un'arma, un mezzo, una persona o un'organizzazione la cui voce riguarda in modo centrale la Seconda guerra mondiale |
| C03 | comune "provincia di Torino" | un comune della provincia (oggi città metropolitana) di Torino, o la provincia stessa |
| C04 | chiesa barocca | una chiesa in stile barocco, o un architetto noto soprattutto per chiese barocche |
| C05 | album rock | un album di musica rock (anche sottogeneri), o la discografia di un gruppo rock |
| C06 | "film commedia" | un film commedia |
| C07 | fiume affluente | un fiume che è affluente di un altro fiume |
| C08 | pittore rinascimentale | un pittore attivo nel Rinascimento, o la pittura rinascimentale |
| C09 | specie coleotteri | una specie (o un genere) di coleotteri, o un entomologo che li ha studiati |
| C10 | pilota "formula 1" | un pilota di Formula 1, o una gara, una vettura o un'organizzazione della Formula 1 |
| C11 | cattedrale gotica | una cattedrale o un duomo in stile gotico |
| C12 | romanzo giallo | un romanzo giallo/poliziesco, il genere giallo o un suo autore |
| C13 | vulcano eruzione | un vulcano o un'eruzione vulcanica |
| C14 | dell'impero romano | l'Impero romano antico (non il Sacro Romano Impero né l'Impero bizantino) |
| C15 | città portuale | una città la cui voce ne evidenzia il porto o l'attività portuale |
